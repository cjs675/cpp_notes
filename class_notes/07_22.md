## Stack Operations 

- **LIFO** 
	- structure developed to store data in a very specific way 
	- two independent approaches: 
		- procedural
		- objective 
- simplest method to store int values -->**vector** 
- (ex.) 
	```cpp
	int stack[100];
	```
	- we also need a variable that can be responsible for **storing** number of elements currently stored on the stack 
		- **SP** (stack pointer) 
		- initial value --> 0 
```cpp
int SP = 0
```

- ** Push** 
	- gets one parameter of type **int** 
		- value to be placed onto the stack 
		- returns nothing 
		- places parameter value into first free element in the vector & increments the SP 
```cpp
void push(int value) {
	stack[SP++] = value;
}
```


**Pop** 
- doesnt have any parameters 
- function returns the value taken from the stack 
- reads top most value in the stack & decrements the stack 

```cpp
int pop(void) {
	return stack[--SP];
}
```

** Stack Methods** 
- stack class provides various methods to perform different ops on a stack 

- push() 
	- adds element into stack 
- pop()
	- removes top most element from the stack 
- top() 
	- returns the element at top of the stack 
- size() 
	- returns number of elements in the stack 
- empty() 
	- returns true if stack is empty

**Enums**

	- consists of set of named integral constants 
	- assign names to integral values, making the code more readable & manageable

		- (ex.)

			- states of a process 
```cpp

	Constant1,

	//
};
```



**templates** 
- pass data type as a parameter so that we dont need to write the same code for different data types 
- can use either **typename** or **class** 

```cpp
template <class identifier> function_declaration;
template <typename identifier> function_declaration
```

```cpp
template <typename T> 
T max_no(T a, T b) {
	return a > b ? a : b
}


int main() {
	cout << max_no(23, 45) << endl;
	cout << max_no(2.45, 8.97);
}
```
#### class template declaration
- class template begins w/ keyword __template__ followed by template args inside **< >** which is followed by class declaration 


```cpp
template <class T>

	private: T var;
	//
	public: 
	T functionName(T arg);
	//

```
